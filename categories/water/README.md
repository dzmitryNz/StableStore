# Вода и средства очистки

## Описание категории

Вода - самый критичный ресурс для выживания. Без воды человек может прожить всего 3-5 дней. Эта категория включает хранение питьевой воды и средства для очистки воды из альтернативных источников.

## Критичность: МАКСИМАЛЬНАЯ

**Правило трех:**
- 3 минуты без воздуха
- 3 дня без воды
- 3 недели без еды

Вода - на втором месте по критичности после воздуха.

## Базовые потребности

### Минимальная норма
- **Выживание**: 1.5-2 литра/день/человек
- **Комфорт**: 3 литра/день/человек (питье + минимальная гигиена)
- **Полноценное использование**: 5+ литров/день/человек (питье, готовка, гигиена)

### Расчет запаса

**На 2 недели (минимум):**
- 1 человек: 3L × 14 дней = 42 литра
- Семья из 4: 42L × 4 = 168 литров

**На 1 месяц:**
- 1 человек: 3L × 30 дней = 90 литров
- Семья из 4: 90L × 4 = 360 литров

## Хранение воды

### Виды тары

**Пластиковые бутылки (ПЭТ):**
- ✓ Легкие, доступные
- ✓ Прозрачные (видно содержимое)
- ✗ Занимают много места
- Срок хранения воды: 6-12 месяцев

**Канистры (food-grade пластик):**
- ✓ Компактнее бутылок
- ✓ Удобная транспортировка
- ✗ Тяжелые когда полные
- Объемы: 5-20 литров

**Бочки/баки:**
- ✓ Большой объем
- ✓ Стационарное хранение
- ✗ Не переносить
- Объемы: 50-200+ литров

### Условия хранения

- **Температура**: 5-20°C (не замораживать, не перегревать)
- **Свет**: Темное место (свет способствует росту водорослей)
- **Тара**: Food-grade пластик или стекло
- **Ротация**: Каждые 6-12 месяцев

### Подготовка к хранению

1. Использовать чистую тару (food-grade)
2. Промыть тару водой с содой
3. Наполнить питьевой водой
4. Плотно закрыть
5. Маркировать (дата розлива)
6. Хранить в прохладном темном месте

## Средства очистки воды

### Фильтры

**Керамические фильтры:**
- Удаляют бактерии, простейшие, мутность
- Ресурс: 5000-10000 литров
- Не требуют электричества
- Можно чистить и переиспользовать

**Угольные фильтры:**
- Удаляют хлор, органику, улучшают вкус
- Ресурс: 1000-3000 литров
- Используются в комбинации с другими

**Мембранные (обратный осмос):**
- Максимальная очистка
- Требуют давление/насос
- Не подходят для автономных условий

### Химическая обеззараживание

**Таблетки с хлором:**
- Убивают бактерии и вирусы
- 1 таблетка на 1-2 литра
- Время действия: 30-60 минут
- Запах хлора

**Йод:**
- 5-10 капель 5% йода на литр
- Время: 30 минут
- Не подходит для беременных
- Запах йода

**Перекись водорода:**
- 1 столовая ложка 3% перекиси на литр
- Менее эффективна, но безопаснее

### Физические методы

**Кипячение:**
- Самый надежный метод
- 100% убивает патогены
- Кипятить 1-3 минуты (на уровне моря)
- Требует топливо

**УФ-стерилизаторы:**
- Портативные устройства
- Убивают бактерии и вирусы
- Требуют батарейки
- Не удаляют мутность

**Дистилляция:**
- 100% очистка
- Очень энергозатратно
- Для экстремальных случаев

### Самодельные фильтры

**Многослойный фильтр:**
```
[Вход грязной воды]
    ↓
[Ткань] - удаление крупных частиц
    ↓
[Песок] - мелкая фильтрация
    ↓
[Уголь] - удаление запахов
    ↓
[Гравий] - поддержка слоев
    ↓
[Выход чистой воды]
```

**Важно**: Самодельные фильтры НЕ обеззараживают! После фильтрации - кипячение или химическая обработка.

## Альтернативные источники воды

### В городе

- Водопроводная вода (если работает)
- Бойлеры и бачки унитазов (техническая, нужна очистка)
- Батареи отопления (техническая, только в крайнем случае)

### За городом

- Дождевая вода (собрать, очистить)
- Реки, озера (обязательно очистить)
- Колодцы (если доступны)
- Снег, лед (растопить, очистить)

### Сбор дождевой воды

**Система:**
1. Чистая поверхность (крыша)
2. Желоба/стоки
3. Емкость для сбора
4. Фильтрация + обеззараживание

**Важно**: Первые минуты дождя пропустить (смывает грязь с крыши).

## Чек-лист категории "Вода"

### Минимальный набор (2 недели)
- [ ] Вода в бутылках: 42L/человек
- [ ] Таблетки для обеззараживания: 20-30 шт
- [ ] Кипячение (есть способ нагреть воду)

### Базовый набор (1 месяц)
- [ ] Вода: 90L/человек
- [ ] Фильтр керамический: 1 шт
- [ ] Таблетки: 50 шт
- [ ] Канистры пустые: 2-3 шт (для сбора)
- [ ] Емкость для кипячения

### Расширенный набор (3+ месяца)
- [ ] Вода: запас + способы пополнения
- [ ] Фильтр качественный (ресурс 5000+ л)
- [ ] Несколько методов очистки
- [ ] Система сбора дождевой воды
- [ ] УФ-стерилизатор (опционально)
- [ ] Тест-полоски для проверки качества

## Типичные ошибки

**Ошибка 1**: "Вода не портится, можно не менять"
- **Решение**: Ротация каждые 6-12 месяцев

**Ошибка 2**: Хранение на солнце
- **Решение**: Темное прохладное место

**Ошибка 3**: Только хранение, нет средств очистки
- **Решение**: Запас воды + способы получить больше

**Ошибка 4**: Незнание как пользоваться фильтрами
- **Решение**: Протестировать заранее

## Приоритеты закупки

1. **Неделя 1**: Вода 40-50 литров + таблетки для обеззараживания
2. **Неделя 2-3**: Довести запас до 100 литров
3. **Неделя 4**: Купить фильтр
4. **Далее**: Расширять запас, дублировать средства очистки
