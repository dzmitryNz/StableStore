# Интеграция с Grocy

CSV файлы для импорта базовых запасов из StableStore в систему учёта Grocy.

## Содержание папки

- `products-essential.csv` - базовые продукты на 1 месяц (из lists/essential.md)
- `locations.csv` - места хранения
- `product-groups.csv` - категории продуктов
- `quantities.csv` - единицы измерения

## Инструкция по импорту

### Шаг 1: Подготовка Grocy

1. Установите и запустите Grocy (https://grocy.info)
2. Откройте веб-интерфейс
3. Войдите в систему (по умолчанию: admin/admin)

### Шаг 2: Импорт базовых данных (в этом порядке!)

**Важно:** Импортируйте файлы строго в указанном порядке, так как есть зависимости.

#### 1. Единицы измерения (Quantities)

**Путь в Grocy:** Manage master data → Quantity units → Import

**Файл:** `quantities.csv`

**Что импортируется:**
- Килограммы (kg)
- Литры (L)
- Штуки (piece)
- Граммы (g)
- Миллилитры (ml)

#### 2. Места хранения (Locations)

**Путь в Grocy:** Manage master data → Locations → Import

**Файл:** `locations.csv`

**Что импортируется:**
- Кладовка
- Полка А
- Полка Б
- Ведро №1, №2, №3
- Холодильник

#### 3. Категории продуктов (Product groups)

**Путь в Grocy:** Manage master data → Product groups → Import

**Файл:** `product-groups.csv`

**Что импортируется:**
- Крупы и макароны
- Бобовые
- Консервы мясные
- Консервы рыбные
- Консервы овощные
- Масло и жиры
- Сахар и соль
- Напитки

#### 4. Продукты (Products)

**Путь в Grocy:** Manage master data → Products → Import

**Файл:** `products-essential.csv`

**Что импортируется:**
Полный список базовых продуктов с:
- Названиями
- Категориями
- Местами хранения
- Единицами измерения
- Примерными сроками годности

### Шаг 3: Добавление запасов

После импорта продуктов добавьте фактические количества:

1. Перейдите в **Stock → Purchase**
2. Выберите продукт
3. Укажите количество
4. Укажите дату покупки
5. Укажите срок годности (Best before)
6. Нажмите **Purchase**

**Или массовый импорт:**

Используйте `stock-initial.csv` для первичного наполнения запасов.

**Путь:** Stock → (три точки) → Import

**Файл:** `stock-initial.csv`

## Формат CSV файлов

### products-essential.csv

```csv
name,location_id,qu_id_stock,product_group_id,min_stock_amount,description
```

**Поля:**
- `name` - название продукта (обязательно)
- `location_id` - ID места хранения (1=Кладовка, 2=Полка А, и т.д.)
- `qu_id_stock` - ID единицы измерения (1=kg, 2=L, 3=piece, и т.д.)
- `product_group_id` - ID категории
- `min_stock_amount` - минимальное количество для уведомления
- `description` - описание (опционально)

### stock-initial.csv

```csv
product_id,amount,best_before_date,purchased_date,price,location_id
```

**Поля:**
- `product_id` - ID продукта (из Grocy после импорта products)
- `amount` - количество
- `best_before_date` - срок годности (формат: YYYY-MM-DD)
- `purchased_date` - дата покупки (формат: YYYY-MM-DD)
- `price` - цена (опционально)
- `location_id` - ID места хранения

## Адаптация под вашу семью

### Расчёт количеств

Базовые CSV содержат количества на **1 взрослого на 1 месяц**.

**Для вашей семьи:**
```
Количество в CSV × Количество людей × Коэффициент
```

**Коэффициенты:**
- Взрослый: 1.0
- Ребёнок 10-15 лет: 0.8
- Ребёнок 5-10 лет: 0.6
- Ребёнок до 5 лет: 0.3-0.4

**Пример:**
Семья: 2 взрослых + ребёнок 8 лет
- Рис в CSV: 5 кг
- Для семьи: 5 × (2 + 0.6) = 5 × 2.6 = 13 кг

### Изменение мест хранения

Отредактируйте `locations.csv` под ваши реальные места:
- Кладовка → Ваше название
- Добавьте свои места (Подвал, Балкон, и т.д.)

## Экспорт из Grocy

Для резервного копирования регулярно экспортируйте данные:

1. **Stock → (три точки) → Export**
2. Сохраните CSV
3. Храните как резервную копию

**Рекомендуемая частота:** Раз в месяц

## Автоматизация (продвинутый уровень)

### Использование Grocy API

```bash
# Получить список продуктов
curl -X GET "http://your-grocy/api/objects/products" \
  -H "GROCY-API-KEY: your-key-here"

# Добавить продукт в запас
curl -X POST "http://your-grocy/api/stock/products/1/add" \
  -H "GROCY-API-KEY: your-key-here" \
  -H "Content-Type: application/json" \
  -d '{"amount": 10, "best_before_date": "2028-01-01"}'
```

**Документация API:** https://demo.grocy.info/api

### Скрипт Python для синхронизации

См. файл `sync-script-example.py` (если нужен - запросите создание)

## Устранение проблем

### Ошибка импорта: "Invalid CSV format"

**Решение:**
- Убедитесь что CSV в кодировке UTF-8
- Используйте запятую как разделитель
- Первая строка должна быть заголовком

### Ошибка: "Location not found"

**Решение:**
- Сначала импортируйте `locations.csv`
- Затем импортируйте `products-essential.csv`

### Продукт не отображается

**Решение:**
- Импорт продуктов ≠ добавление в запас
- После импорта используйте Stock → Purchase для добавления количеств
- Или импортируйте `stock-initial.csv`

## Обновление данных

### При обновлении StableStore

1. Скачайте новые CSV из репозитория
2. Сравните с вашими текущими данными
3. Добавьте новые продукты через Import
4. Или отредактируйте существующие вручную

### Синхронизация с бумажным учётом

Если ведёте учёт на бумаге параллельно:
- Раз в неделю: сверяйте Grocy с бумажным списком
- Или экспортируйте из Grocy и печатайте для инспекций
