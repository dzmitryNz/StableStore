## Планирование запасов

### Промпт 1: Создание базового списка

```
Составь список запасов на [СРОК] для [КОЛИЧЕСТВО] человек.

Условия:
- Бюджет: [ограниченный / средний / без ограничений]
- Доступное место: [мало / средне / много]
- Особые требования: [аллергии, диеты, дети, и т.д.]
- Приоритет: [скорость / стоимость / качество / разнообразие]

Включи:
1. Конкретные количества по категориям
2. Приоритизацию покупок
3. Оценку необходимого места хранения
4. Предварительную стоимость (low/medium/high)
```

**Пример использования:**
```
Составь список запасов на 3 месяца для 4 человек (2 взрослых, 2 детей 6 и 10 лет).

Условия:
- Бюджет: средний
- Доступное место: средне (кладовка 2×2м + балкон)
- Особые требования: у ребенка аллергия на орехи
- Приоритет: разнообразие и питательность

Включи: [...]
```

### Промпт 2: Расширение существующих запасов

```
Проанализируй мои текущие запасы и предложи, что добавить.

Текущие запасы:
[перечисление того, что уже есть]

Цель: увеличить автономность с [ТЕКУЩИЙ СРОК] до [ЦЕЛЕВОЙ СРОК]
Количество людей: [N]
Бюджет на расширение: [СУММА или уровень]

Укажи:
1. Критические пробелы (что нужно в первую очередь)
2. Рекомендуемые дополнения
3. Что можно отложить
4. Порядок приобретения
```

### Промпт 3: Специализированный сценарий

```
Составь список запасов для сценария: [ОПИСАНИЕ СЦЕНАРИЯ]

Параметры:
- Срок: [длительность ситуации]
- Люди: [количество и особенности]
- Условия: [наличие электричества, воды, отопления]
- Мобильность: [нужно оставаться дома / возможна эвакуация]

Сфокусируйся на:
[специфические требования сценария]
```

**Примеры сценариев:**
- Длительный перебой электроэнергии зимой
- Карантин с детьми
- Наводнение (эвакуация возможна)
- Экономический кризис (длительная экономия)

## Анализ условий хранения

### Промпт 4: Оценка места хранения

```
Помоги оптимизировать хранение запасов.

Доступные места:
1. [Описание места 1: размер, температура, влажность, освещение]
2. [Описание места 2: ...]
3. [...]

Что нужно хранить:
[Список категорий и примерных объемов]

Предложи:
1. Какие продукты в какие места
2. Как организовать систему хранения
3. Что докупить для хранения (тара, полки, и т.д.)
4. Как обеспечить ротацию
```

### Промпт 5: Проверка условий для конкретного продукта

```
Можно ли хранить [ПРОДУКТ] в следующих условиях:
- Место: [описание]
- Температура: [диапазон]
- Влажность: [уровень]
- Освещение: [естественное/искусственное/темно]
- Тара: [описание упаковки]

Если нет - что нужно изменить?
Какой реальный срок хранения в этих условиях?
```

## Расчеты и оценки

### Промпт 6: Расчет необходимого количества

```
Рассчитай необходимое количество [ПРОДУКТ/КАТЕГОРИЯ] на:
- Срок: [период]
- Людей: [количество, возраст, особенности]
- Режим потребления: [обычный / экономный / обильный]

Учти:
- Коэффициент запаса
- Потери при хранении
- Вариативность потребления
```

### Промпт 7: Оценка пространства

```
Сколько места займет:
[Список продуктов с количествами]

Укажи:
- Объем в кубометрах
- Сколько нужно полок (60×40 cm)
- Сколько ведер (20L)
- Альтернативные способы размещения
```

### Промпт 8: Калорийность и питательность

```
Проанализируй список на калорийность и сбалансированность:

[Список продуктов с количествами]

На срок: [период]
Для: [количество людей]

Проверь:
1. Достаточно ли калорий (норма 2000-2500 ккал/день/человек)
2. Баланс белков/жиров/углеводов
3. Критические недостатки (витамины, минералы)
4. Предложи корректировки
```

## Оптимизация

### Промпт 9: Сокращение бюджета

```
У меня есть список запасов, но бюджет ограничен.

Исходный список:
[...]

Доступный бюджет: [СУММА или "сократить на X%"]

Помоги:
1. Определить абсолютный минимум (что нельзя убрать)
2. Что можно заменить более дешевыми аналогами
3. От чего можно временно отказаться
4. Как поэтапно собрать полный список
```

### Промпт 10: Оптимизация пространства

```
Нужно разместить запасы в ограниченном пространстве.

Доступно: [размеры, характеристики места]

Запасы на: [срок] для [количество] людей

Предложи:
1. Самые компактные варианты продуктов
2. Способы уплотнения хранения
3. Что выбрать, если не все помещается
4. Как использовать нестандартные места
```

### Промпт 11: Улучшение ротации

```
У меня проблемы с ротацией запасов - часть продуктов просрочивается.

Текущая система:
[Описание как сейчас организовано]

Что хранится:
[Категории и примерные объемы]

Помоги разработать систему ротации, которую легко поддерживать.
```

## Обучение и информация

### Промпт 12: Объяснение метода хранения

```
Объясни подробно, как правильно хранить [ПРОДУКТ/КАТЕГОРИЯ]:
1. Оптимальные условия
2. Подготовка к хранению
3. Выбор тары
4. Срок хранения (реальный)
5. Признаки порчи
6. Частые ошибки
```

### Промпт 13: Сравнение вариантов

```
Сравни варианты для [ЦЕЛЬ]:

Вариант 1: [описание]
Вариант 2: [описание]
Вариант 3: [описание]

Критерии:
- Стоимость
- Срок хранения
- Простота использования
- Эффективность
- [дополнительные критерии]

Порекомендуй лучший вариант для моей ситуации: [описание ситуации]
```

### Промпт 14: Многофункциональность

```
Какие есть альтернативные применения для [ПРЕДМЕТ/ПРОДУКТ]?

Контекст: создание запасов, нужны многофункциональные вещи.

Укажи:
- Основное применение
- Альтернативные использования
- В каких ситуациях какое применение
- Есть ли более универсальная альтернатива
```

## Аудит и проверка

### Промпт 15: Комплексный аудит запасов

```
Проведи аудит моих запасов:

Текущие запасы:
[Подробный список с количествами и датами]

Условия хранения:
[Описание мест и условий]

Цель: запас на [СРОК] для [ЛЮДЕЙ]

Проверь:
1. Достаточность по всем категориям
2. Баланс и сбалансированность
3. Адекватность условий хранения
4. Критические проблемы
5. Приоритетные улучшения
```

### Промпт 16: Проверка перед чрезвычайной ситуацией

```
Возможна [СИТУАЦИЯ] в ближайшее время.

Мои запасы:
[Список]

Проверь готовность:
1. Чего критически не хватает
2. Что нужно докупить срочно (и можно ли еще)
3. Как оптимизировать имеющееся
4. Что подготовить для быстрого доступа
5. Альтернативные планы, если чего-то не достать
```

## Специальные промпты

### Промпт 17: План действий

```
Создай пошаговый план создания запасов с нуля.

Начальные условия:
- Бюджет: [в месяц можно выделять]
- Место: [что доступно]
- Цель: [срок автономности]
- Люди: [количество]

Распиши план на 6-12 месяцев:
- Что покупать в первую очередь
- Порядок приобретений
- Когда что организовывать
- Контрольные точки проверки
```

### Промпт 18: Адаптация под регион

```
Адаптируй рекомендации под мой регион:
- Климат: [описание]
- Доступность продуктов: [что легко/сложно достать]
- Местные особенности: [культурные, кулинарные]
- Типичные угрозы: [землетрясения, наводнения, и т.д.]

Базовый список:
[стандартный список запасов]

Предложи региональную адаптацию.
```

### Промпт 19: Бюджетный старт

```
Хочу начать создавать запасы, но бюджет очень ограничен.

Могу выделять: [СУММА] в месяц
Цель: минимальная страховка на [СРОК]
Людей: [КОЛИЧЕСТВО]

Составь план минимального старта:
1. Что купить в первый месяц (самое критичное)
2. Порядок наращивания
3. Где экономить безопасно
4. Как не потратить деньги впустую
```

## Шаблоны для создания контента

### Промпт 20: Создание описания продукта

```
Создай описание для продукта [НАЗВАНИЕ] по шаблону:

---
category: [категория]
shelf_life: [срок]
storage_conditions: [условия]
priority: [уровень]
tags: [теги]
---

# [Название продукта]

## Описание
[Что это, зачем нужно]

## Характеристики хранения
- Срок: [детали]
- Условия: [температура, влажность, свет]
- Тара: [рекомендации]

## Применение
[Как используется]

## Альтернативы
[Чем можно заменить]

## Важные заметки
[Особенности, предупреждения]
```

## Комбинированные сценарии

### Промпт 21: Полное планирование

```
Помоги создать комплексный план запасов.

Исходные данные:
- Семья: [состав]
- Бюджет: [уровень]
- Пространство: [описание]
- Сценарии: [для чего готовимся]
- Срок: [горизонт планирования]
- Ограничения: [диета, аллергии, и т.д.]

Нужен полный план:
1. Список по категориям с количествами
2. Организация хранения
3. График закупок (поэтапно)
4. Система ротации
5. Контрольные чек-листы
6. План на первые 30/60/90 дней
```

---

## Примечания по использованию

- **Квадратные скобки [...]** - места для заполнения вашими данными
- **Слэш /** - выбрать один из вариантов
- **КАПС** - обязательные данные для заполнения

Эти промпты можно комбинировать и адаптировать под конкретные задачи.
