# Контекст проекта StableStore

## Цель проекта

Создание практической базы знаний для долгосрочного планирования и управления запасами продуктов, материалов и необходимых вещей для обеспечения автономности в сложных жизненных ситуациях.

## Целевая аудитория

- Люди, планирующие создание продовольственных запасов
- Те, кто стремится к большей автономности и самообеспеченности
- Семьи, заботящиеся о продовольственной безопасности
- Практики минимализма и эффективного использования ресурсов

## Философия проекта

### Практичность

Только проверенные, реально применимые решения. Никакой паники, алармизма или экстремизма. Запасы - это нормальная практика рачительного хозяйства.

### Многофункциональность

Предпочтение отдается предметам и продуктам, которые имеют несколько способов применения. Избегаем узкоспециализированных вещей, если есть универсальные альтернативы.

### Долгосрочность

Фокус на решениях для длительного хранения, но с обязательной ротацией и интеграцией в повседневную жизнь.

### Сбалансированность

Не только выживание, но и комфорт. Учитываем психологические аспекты, разнообразие питания, качество жизни.

## Ключевые концепции

### 1. Многоуровневая система запасов

**Уровень 1: Повседневный (1-2 недели)**
- То, что используется ежедневно
- Максимальная свежесть
- В кухонных шкафах и холодильнике

**Уровень 2: Краткосрочный (1-3 месяца)**
- Базовые продукты длительного хранения
- Активная ротация
- Интеграция в обычное питание

**Уровень 3: Среднесрочный (3-12 месяцев)**
- Запасы на случай потери дохода, кризиса
- Средняя ротация
- Требует организации хранения

**Уровень 4: Долгосрочный (1-5+ лет)**
- Стратегический резерв
- Минимальная или нулевая ротация
- Оптимальные условия хранения

### 2. Система FIFO (First In, First Out)

Основа ротации запасов:
- Новое - назад
- Старое - вперед
- Регулярная инспекция
- Использование в повседневной жизни

### 3. Правило трех врагов хранения

- **Температура** → прохладное место
- **Влажность** → сухое место
- **Свет** → темное место

### 4. Матрица приоритетов

```
Критичность × Срок хранения = Приоритет закупки

Высокая критичность + Долгий срок = Купить первым
Высокая критичность + Короткий срок = Ротация обязательна
Низкая критичность + Долгий срок = Купить при возможности
Низкая критичность + Короткий срок = Не для запасов
```

## Типичные сценарии использования

### Сценарий 1: Потеря дохода
- Срок: 3-6 месяцев
- Приоритет: Базовые калории, низкая стоимость
- Особенности: Сохранение нормального питания при минимальных расходах

### Сценарий 2: Природная катастрофа
- Срок: 1-4 недели
- Приоритет: Вода, продукты без приготовления, автономность
- Особенности: Возможное отсутствие электричества и воды

### Сценарий 3: Пандемия/карантин
- Срок: 2-8 недель
- Приоритет: Разнообразие, витамины, психологический комфорт
- Особенности: Длительная изоляция, стресс

### Сценарий 4: Экономический кризис
- Срок: 6-24 месяца
- Приоритет: Ценность сохранения, возможность обмена
- Особенности: Инфляция, дефицит некоторых товаров

## Принципы организации данных

### Структура файлов

```
Заголовок (H1) - название темы
├── Описание - краткое введение
├── Основные разделы (H2) - логические блоки
│   ├── Подразделы (H3) - детализация
│   └── Примеры - практические иллюстрации
├── Чек-листы - actionable items
└── Связи - ссылки на связанные темы
```

### YAML Frontmatter

Обязательные поля:
```yaml
---
category: основная_категория/подкатегория
tags: [тег1, тег2, тег3]
priority: critical/high/medium/low
updated: YYYY-MM-DD
---
```

Опциональные поля:
```yaml
shelf_life: описание срока хранения
storage_conditions: условия хранения
cost_level: low/medium/high
multifunctional: true/false
alternative_uses: [применение1, применение2]
```

### Соглашения по ссылкам

- `[[file-name]]` - ссылка на другой файл
- `[[file-name|Отображаемый текст]]` - ссылка с кастомным текстом
- `#тег` - для категоризации и поиска
- `#категория/подкатегория` - иерархические теги

## Метрики и расчеты

### Базовые нормы (на человека в день)

```
Вода: 3 L
Калории: 2000-2500 ккал
Белок: 50-70 г
Крупы/макароны: 300-400 г (сухой вес)
Бобовые: 50-100 г (сухой вес)
Масло: 30-50 ml
Сахар: 50-70 г
Соль: 10-15 g
```

### Расчет объемов хранения

- 1 ведро (5 gallon / 20L) ≈ 12-15 кг сыпучих продуктов
- 1 полка (60×40 cm) ≈ 30-40 банок консервов
- 1 кв.м стеллажей (5 полок) ≈ запас на 2-3 месяца для 1 человека

### Стоимостные оценки

Избегаем конкретных цен (быстро устаревают), используем:
- `cost_level: low` - доступно для любого бюджета
- `cost_level: medium` - требует планирования расходов
- `cost_level: high` - значительные инвестиции

## Терминология

### Основные термины

- **Ротация** - систематическое использование старых запасов и пополнение новыми
- **Абсорбент кислорода** - пакетик с железным порошком, поглощающий O₂
- **Майлар** - металлизированная многослойная пленка для хранения
- **Food-grade** - пластик, безопасный для контакта с пищей
- **Gamma lid** - удобная завинчивающаяся крышка для ведер
- **FIFO** - First In, First Out (первым пришел - первым ушел)

### Категории продуктов

- **Staples** - основные продукты (крупы, бобовые, соль, сахар)
- **Calorie-dense** - калорийно-плотные продукты
- **Shelf-stable** - продукты для хранения без холодильника
- **Ready-to-eat** - готовые к употреблению без приготовления
