# StableStore

Система управления долгосрочным хранением продуктов и запасов для сложных жизненных ситуаций.

## Описание проекта

StableStore - это база знаний и система планирования для создания и поддержания запасов продуктов, материалов и необходимых вещей на случай различных жизненных ситуаций. Проект фокусируется на практичности, многофункциональности предметов и оптимальных методах хранения.

## Ключевые особенности

- **Человекочитаемый формат**: Все данные хранятся в текстовых файлах формата Markdown
- **Совместимость с Obsidian**: Структура оптимизирована для работы в Obsidian и аналогичных приложениях
- **AI-friendly**: Структура данных разработана для эффективной работы с AI агентами
- **Практичность**: Акцент на многофункциональные предметы и реальные потребности
- **Систематизация**: Четкая категоризация и связи между элементами

## Быстрый старт

1. **Навигация**: Смотрите `CONTENTS.md` - полный указатель всех материалов
2. **Для начинающих**: Начните с `GETTING-STARTED.md`
3. **Изучите теорию**: Файлы в папке `theory/`, особенно `storage-basics.md`
4. **Определите потребности**: Используйте `lists/essential.md` как отправную точку
5. **Планируйте хранение**: Следуйте рекомендациям из `guides/`
6. **Ведите учет**: Создавайте файлы на основе шаблонов в `templates/`

## Работа с Obsidian

Проект полностью совместим с Obsidian:
- Используйте двойные квадратные скобки `[[ссылка]]` для связей между заметками
- Теги в формате `#категория/подкатегория` для организации
- Dataview-совместимые метаданные в YAML frontmatter

## Работа с AI агентами

Файлы в папке `.ai/` содержат:
- Контекст проекта для LLM
- Готовые промпты для планирования и анализа
- Инструкции по структуре данных
- Планирование и учёт изменений (`agent-tasks.md`)

## Принципы проекта

1. **Практичность превыше всего**: Только проверенные решения
2. **Многофункциональность**: Предпочтение предметам с несколькими применениями
3. **Долгосрочность**: Фокус на длительном хранении
4. **Доступность**: Все должно быть реально приобретаемо и применимо
5. **Гибкость**: Адаптация под разные условия и ситуации

## Содействие проекту

- Используйте понятный язык

- Указывайте источники информации
