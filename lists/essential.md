# Базовый список необходимого

Минимальный набор запасов для обеспечения автономности семьи на 1 месяц.

## Критические позиции

### 1. Вода (наивысший приоритет)

**На человека:**
- Питьевая вода: 90L (3L × 30 дней)
- Средства очистки воды:
  - [ ] Фильтр керамический/угольный (ресурс на 1000+ литров)
  - [ ] Таблетки для обеззараживания (50-100 шт)
  - [ ] Емкости для хранения (канистры, бутыли)

**Альтернативы:**
- Система очистки дождевой воды
- Кипячение (требует топливо)

### 2. Базовые калории (крупы и зерновые)

**На человека на месяц:**
- [ ] Рис белый: 5 кг
- [ ] Гречка: 2 кг
- [ ] Овсянка: 2 кг
- [ ] Макароны: 3 кг
- [ ] Мука: 2 кг

**Итого:** ~14 кг / ~10,000 ккал

### 3. Белок

**На человека на месяц:**
- [ ] Консервы мясные: 3 кг (6-8 банок по 400г)
- [ ] Консервы рыбные: 2 кг (10-12 банок по 200г)
- [ ] Бобовые сушеные:
  - Фасоль: 1.5 кг
  - Чечевица: 1 кг
  - Горох: 0.5 кг

**Итого:** ~6 кг бобовых + 5 кг консервов

### 4. Жиры и масла

**На человека на месяц:**
- [ ] Масло растительное: 1 литр
- [ ] Масло для жарки (рафинированное): дополнительно 0.5л

### 5. Сахар и соль

**На человека на месяц:**
- [ ] Сахар: 2 кг
- [ ] Соль: 0.5 кг

## Важные позиции

### 6. Овощи и фрукты (консервированные)

**На человека на месяц:**
- [ ] Томаты консервированные: 2 кг (2-3 банки)
- [ ] Овощные консервы (кукуруза, горошек): 1.5 кг
- [ ] Фрукты консервированные: 1 кг
- [ ] Томатная паста: 2-3 тубы
- [ ] Варенье/джем: 0.5-1 кг

### 7. Молочные продукты (длительного хранения)

**На человека на месяц:**
- [ ] Сухое молоко: 1 кг
- [ ] Сгущенное молоко: 2-3 банки

### 8. Специи и приправы

**Базовый набор:**
- [ ] Перец черный молотый: 100г
- [ ] Лавровый лист: 1 упаковка
- [ ] Чеснок сушеный: 50г
- [ ] Паприка: 100г
- [ ] Уксус: 0.5л
- [ ] Соевый соус: 0.5л
- [ ] Бульонные кубики: 20-30 шт

### 9. Напитки

**На человека на месяц:**
- [ ] Чай: 200-300г
- [ ] Кофе (если пьете): 300г
- [ ] Какао: 200г

## Энергия и приготовление пищи

### 10. Топливо для готовки

**Варианты:**
- [ ] Газовые баллоны туристические: 5-8 шт (на месяц для семьи)
- [ ] Спиртовка + топливо: 2-3 литра спирта
- [ ] Твердотопливные таблетки: 50-100 шт

**Оборудование:**
- [ ] Газовая горелка туристическая
- [ ] Спички водостойкие: 3-5 коробков
- [ ] Зажигалки: 5-10 шт

### 11. Освещение

- [ ] Фонарики LED: 3-5 шт
- [ ] Батарейки (AA, AAA): 50+ шт
- [ ] Свечи: 20-30 шт (100+ часов горения)
- [ ] Налобный фонарь: 1-2 шт
- [ ] Аккумуляторные батарейки + зарядка

## Медицина и гигиена

### 12. Базовая аптечка

**Перевязочные материалы:**
- [ ] Бинты стерильные: 5-10 шт
- [ ] Лейкопластырь: 2-3 упаковки
- [ ] Вата: 100г
- [ ] Марлевые салфетки: 10-20 шт

**Медикаменты:**
- [ ] Перекись водорода: 2 флакона
- [ ] Йод/зеленка: 2 флакона
- [ ] Обезболивающее (парацетамол, ибупрофен): 20-40 таблеток
- [ ] Жаропонижающее: 20 таблеток
- [ ] Активированный уголь: 50 таблеток
- [ ] Средство от диареи: 10-20 таблеток
- [ ] Антигистаминное: 10-20 таблеток
- [ ] Регулярные лекарства: запас на 3 месяца

**Инструменты:**
- [ ] Ножницы медицинские
- [ ] Пинцет
- [ ] Термометр
- [ ] Жгут

### 13. Средства гигиены

**На человека на месяц:**
- [ ] Мыло кусковое: 2-3 куска
- [ ] Зубная паста: 1 тюбик
- [ ] Зубные щетки: 2 шт
- [ ] Туалетная бумага: 8-12 рулонов
- [ ] Влажные салфетки: 3-5 упаковок
- [ ] Дезинфицирующее средство для рук: 0.5л
- [ ] Шампунь/мыло жидкое: 0.5л
- [ ] Стиральный порошок: 1 кг

**Для женщин:**
- [ ] Прокладки/тампоны: запас на 3-6 месяцев

**Для детей:**
- [ ] Подгузники: запас на 1-2 месяца
- [ ] Детские салфетки
- [ ] Крем под подгузник

## Инструменты и оборудование

### 14. Базовые инструменты

- [ ] Нож многофункциональный (швейцарский/мультитул)
- [ ] Открывалка консервная (механическая)
- [ ] Ножницы
- [ ] Изолента: 2-3 рулона
- [ ] Веревка/шнур: 20-50 метров
- [ ] Мусорные пакеты прочные: 50-100 шт

### 15. Коммуникация и информация

- [ ] Радио на батарейках (AM/FM)
- [ ] Внешние аккумуляторы (20000+ mAh): 2-3 шт
- [ ] Зарядные кабели для всех устройств
- [ ] Свисток для сигнализации
- [ ] Блокнот и ручки

### 16. Документы

- [ ] Копии важных документов (паспорта, свидетельства)
- [ ] Медицинские записи
- [ ] Страховые полисы
- [ ] Список важных контактов (на бумаге)
- [ ] Наличные деньги (мелкие купюры): запас на 1-2 недели расходов

## Комфорт и психологическая поддержка

### 17. Для поддержания морального духа

- [ ] Шоколад/конфеты: 1-2 кг
- [ ] Печенье: 2-3 пачки
- [ ] Любимые лакомства семьи
- [ ] Настольные игры/карты
- [ ] Книги
- [ ] Блокноты для рисования (для детей)

## Расчет на семью

### Пример: Семья из 4 человек (2 взрослых, 2 детей 6 и 10 лет)

**Коэффициенты:**
- Взрослый: 1.0
- Ребенок 10 лет: 0.8
- Ребенок 6 лет: 0.6
**Итого:** 2 + 0.8 + 0.6 = 3.4 взрослых эквивалента

**Базовые продукты (на месяц):**
- Рис: 5 кг × 3.4 = 17 кг
- Гречка: 2 кг × 3.4 = 6.8 кг → 7 кг
- Макароны: 3 кг × 3.4 = 10.2 кг → 10 кг
- Мука: 2 кг × 3.4 = 6.8 кг → 7 кг
- Бобовые: 3 кг × 3.4 = 10.2 кг → 10 кг
- Масло: 1л × 3.4 = 3.4л → 3.5-4л
- Сахар: 2 кг × 3.4 = 6.8 кг → 7 кг
- Соль: 0.5 кг × 3.4 = 1.7 кг → 2 кг

**Вода:**
90L × 3.4 = 306 литров → **~310 литров**

## Хранение

### Необходимое пространство (примерно)

Для 4 человек на месяц:
- Вода: ~310л → 52 бутыли по 6л (или эквивалент)
- Сыпучие продукты: ~60 кг → 4-5 ведер по 20л
- Консервы: ~50-60 банок → 2-3 коробки или 1.5 полки
- Прочее: 1-2 коробки

**Итого:** ~2-3 кв.м. площади полок/стеллажей

## Примечания

- Количества даны для взрослого человека
