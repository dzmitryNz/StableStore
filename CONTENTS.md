## ℹ️ Примечания

- ✅ **Готово** - файл создан и содержит полную информацию
- 📝 **Планируется** - файл в планах разработки
- 🔄 **В работе** - файл создаётся в данный момент
- ⚠️ **Требует обновления** - файл устарел и нуждается в ревизии

**Символы в ссылках Obsidian:**
- `[[file]]` - ссылка на файл
- `[[file|Текст]]` - ссылка с пользовательским текстом
- `[[folder/file]]` - ссылка с указанием пути

**Для навигации:**
- Используйте Ctrl+Click (или Cmd+Click на Mac) для перехода по ссылкам в Obsidian
- В обычном markdown-редакторе используйте относительные пути
